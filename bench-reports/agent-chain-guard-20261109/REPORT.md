# 快照链保护：Agent 命中 c=4 9.8%→30.7%（2026-11-09）

## 一、改动

**radix.rs**（wein-memory）新增两个方法 + m11c/m11d 测试：
- `pin_block(pool, block)`：DFS 找块 → lock_ref+1 + pool.retain（驱逐免疫）
- `unpin_block(pool, block)`：对称解除（不在树静默返回）

**qwen.rs**（wein-exec）三处接线，pin 生命周期严格跟随 `snap_of_block` 表：
1. 退场挂表时 pin（幂等：重准入继承的槽已在表则跳过）
2. 还池分支 / release_slot 摘表时 unpin
3. `clear_prefix_cache` 先全解保护再 evict（否则 reset 清不动 pin 块）

语义：**挂快照的块驱逐免疫，LRU 只能摘链尾到快照点为止**——多会话互逐下
匹配深度保得住。32 快照 × 1 块 pin（非整链 pin，后者会吃穿池）。
