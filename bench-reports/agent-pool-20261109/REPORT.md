# Agent 命中率并发衰减：曲线定档 + 池容量实验（2026-11-09，生产零改动）

> 问题：c=1 命中 71.7%（≈理论上限），c=16 只有 15-20% vs vLLM 67.8%。
> 本刀测出衰减曲线，并用池实验把损失拆成两个成分。**生产保持 512 页现状。**

## 一、衰减曲线（512 页标准口径，turns=6，单发）

| 并发 | 命中率 |
|---|---|
| c=1 | 71.7%（历史上限口径） |
| c=2 | 37.8% |
| c=4 | 9.8% |
| c=8 | 17.8% |
| c=16 | 10.2-19.9%（多档波动） |

**c=2 就腰斩**。

## 二、池容量实验：对 c=2 是实锤，对 c=16 无效

| 配置 | c | 命中 | ITL | 热 TTFT |
|---|---|---|---|---|
| 512 页（8K tok） | 2 | 37.8% | — | — |
| **2048 页（32K）** | **2** | **67.5%** | 12.57ms | **333ms** |
| 2048 页 | 16 | 15-27% | 14.0-16.2 | 3654-4259ms ❌ |
| 2048 页 + mix_cap 96 | 16 | 16-20% | 32-33 | 10-13s ❌ |
| 4096 页（64K） | 16 | 16-22% | 34.7 | 4.8-6.0s ❌ |

结论：
1. **c=2 的损失 100% 是 KV 池容量**（块驱逐）：两链交替互逐，32K 池即恢复。
2. **c=16 的损失不止池**：64K 池（> 16×2.2K 需求）命中仍 16-22% ⇒ 存在第二损失源
   （候选：快照采集时机、retain 借还竞争、多请求 admit 路径）。
3. **大池伤调度**：can_admit 水位随池放宽 ⇒ 同步 prefill 并发升 ⇒ 每步批重 ⇒
   ITL/TTFT 崩。c=16 加大池必须配准入收紧，而 mix_cap 96 收太狠（吞吐崩）。
4. vLLM 67.8% 的代价：他们的 KV/状态缓存共享块引用计数语义 + 更大默认预算。

c=16×3 整场只有 2 条 admit（冷启那条）。dbg5 线索 `retain seq=19 snaps=[]`——
请求退场时无快照持有，是否= 采集丢失未定论。**先修仪器再定位。**

## 四、生产决定

保持 `--kv-pages 512` 默认。c=2 场景的用户可自配 2048 页（文档化收益 +30pt 命中）。
