# deltanet decode：跨 lane 归约搬进 smem（302→238µs，满载 +6.9~11%）

## 0. 一句话
把 kvm/o 的跨 lane 归约交换区从**全局 scratch**搬进**块内 smem**（每 warp 1056 f32、行跨度 33），
并把第二级折叠的**执行者**从"每 lane 各折一遍同一行"改成"lane b 折第 b 行"（归约树形状一字未变）：
`deltanet` decode 单发 **336→238µs（640→880 GB/s，纯拷贝上限的 98%）**，满载 tps **3661.6/3694.2 → 3939.3/3936.5（+6.9%）**。

## 1. 靶心是怎么找到的（nsys 推翻"空洞"判断）
此前 eager 段表说"空洞 2.19ms/步"，据此把下一刀定为"碎算子/空洞合并"。用 nsys 抓图形档 c=100 满载后：

- 单步 23.46ms 的 kernel busy 合计 **23.46ms**，而 ITL p50 = 23.75 ⇒ **图形档真空洞只有 0.3ms**（eager 的 2.19 是主机侧
  launch 串行，图档已经吃掉）。**"碎算子/空洞"这条靶子作废。**
- 按 kernel 名折算每步：**gemm 13.37 / delta 8.21 / norm+eltw 1.05 / attn 0.42 / 其它 0.41**。
- delta 里 `deltanet` 一柱擎天：**22.5 发/步 × 336µs = 7.56ms/步（32%）**，而 vLLM 同功能整桶只 5.22ms/步。
- 该 launch 的固有流量 = 状态池 100 行 × 32 v 头 × 128² × 2B × 2（读+写）= **209.7MB** ⇒ 336µs = **639 GB/s**；
  vLLM 217µs/层 = 920 GB/s ⇒ **同样的字节我们只跑到 64%**。

## 2. 病灶定位（探针分离"几何/占用率"与"算术"）
建 `examples/dn_dec_probe.rs`（同进程交错 A/B + D2D 标定），加"同几何纯拷贝参考"：

| 变体 | 中位 µs | GB/s |
|---|---|---|
| 纯拷贝参考（只读+回写 u64，同 grid/bdim） | **233.3** | **899** |
| 纯拷贝 + 只有 kvm 折叠 | 267.3 | 785 |
| 纯拷贝 + kvm + o 折叠 | 298.8 | 702 |
| 原 kernel | 302.0 | 694 |

⇒ 纯拷贝 233µs 已贴 HBM 天花板，**两趟跨 lane 折叠各吃 34/31µs**，加起来正好等于整 kernel
——病根是"128B/行 × 2 趟 × 全批"的跨 lane 交换走了**全局内存**（约 210MB/发的 L2 往返），不是算术量。

## 3. 改动
1. `DN_SX: [f32; 8*1056]`（`#[link_section=".shared"]`，blockscope smem 33792B）：每 warp 1056 = kvm 528 + o 528，
   行跨度 **33**（写"lane s → 行 b"与折"lane b → 项 u"两向都落不同 bank）。8 warp 上限覆盖 bdim=256。
2. `wslot/oslot` 从 `scratch + bid*nwarps*1024 + w*512` 改成 smem 基址（**spec==1 的 MTP 验证链路径仍走全局 scratch，一字未动**）。
3. `dn_e2!` 里 `kvm` 直接读上一趟 lane 分领折叠写回行首的标量（每 lane 各折 32 项的冗余消失）。
4. `dn_batch!` 增 `$nb`，第二级折叠改 lane b→行 b，kvm/o 各一次；每批 2→3 道屏障。
   **32 项 u 升序加法链形状逐字不变**（红线：`o[v]=Σ_j S[v][j]·k[j]` 的归约树不换形状，只换执行者）。

## 5. 证伪（别再试）
- **几何/占用率**：纯拷贝在 vsplit=1/2/4/8 × bdim=64/128/256 全部 228–235µs（=99–105% D2D），连 24 warp/SM 的 74-reg
  拷贝也是 233µs ⇒ **8 warp/SM 已经打满 HBM**，提占用率无收益。真 kernel 换几何一律更慢（vsplit≥2 → 249–401µs）。
- **屏障成本**：每批插 1/2/3/4/6 道：233.25/233.47/233.24/233.86/233.27µs ⇒ 屏障免费。
- **指令数**：lane 分领折叠把批循环 SASS 2089→1952 条（−6.5%），单独用（不动交换区）300.4→300.4µs，一点没动。
- **"167 regs ⇒ 3 块/SM / 12 warp"** 是旧 build 的数，实测 254 regs ⇒ 2 块/SM / 8 warp，且这并非病灶。
- **220µs 不可达**：同形状 209.7MB 纯拷贝就要 233µs（要 220µs ⇔ 953 GB/s > 实测 D2D 908）。
